# Contributing to CipherRep

CipherRep is in the specification phase. Contributions are welcome for protocol design, threat modeling, workflow clarity, language-neutral formats, cryptographic research, and interoperable test cases.

Before proposing code, identify the relevant spec section, trust assumptions, cryptographic suite, backward-compatibility impact, and test vectors. Prefer small reviewable changes. Cryptographic changes should include known failure modes and independent references. Never present experimental cryptography as production-ready.

Proposed order: resolve v1 trust model and canonical rating-set completeness; select and document a provable encrypted-aggregation construction; finalize encoding and suite registry; publish cross-language vectors; then build reference implementations.
