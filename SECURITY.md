# Security Policy

CipherRep is an experimental protocol specification. There is currently no released secure implementation or supported production version.

For sensitive vulnerabilities, avoid publishing exploit details in a public issue before maintainers can assess them. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise contact the repository owner through an appropriate private channel.

Security claims require a documented threat model, fixed cryptographic parameters, rigorous tests, and independent review. See [spec/threat-model.md](spec/threat-model.md).
