# ADR 0003: Zero-knowledge proof system selection

- **Status:** Proposed — decision pending
- **Date:** 2026-11-14

## Context

Compare SNARK/STARK options with concrete benchmarks and threat assumptions.

## Decision to make

Evaluate proof size, verifier cost, setup, auditability and browser proving feasibility.

## Options and evaluation criteria

Compare security properties, privacy leakage, portability, operational trust, cost, performance, testability and upgrade risk. No option is accepted yet.

## Consequences

To be documented after the decision, including alternatives rejected and any required migration.

## Validation gate

A decision is accepted only with a documented rationale, relevant threat-model update and interoperability tests or benchmarks.
