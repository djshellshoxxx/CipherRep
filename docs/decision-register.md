# Decision register

| Gate | Decision | Status | Blocking |
|---|---|---|---|
| D1 | Canonical eligible-set completeness | Open | Sound aggregation proof |
| D2 | Trust model and custodian deployment | Open | Production privacy guarantees |
| D3 | Encryption, commitments, ZK proof suite | Open | Real cryptographic implementation |
| D4 | Canonical wire encoding and transcript | Open | Stable cross-language vectors |
| D5 | Leakage, freshness and revocation policy | Open | Final privacy claims |

The work in [PLAN.md](../PLAN.md) deliberately proceeds on arithmetic, logical messages, state machines, API surface and conformance conventions without assuming answers to these gates. Accepted decisions MUST be recorded in ADRs and referenced by the normative spec.
